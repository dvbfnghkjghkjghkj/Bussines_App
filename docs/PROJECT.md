## Стек

- **Сборка:** Vite 8
- **UI:** чистый HTML/CSS/JS, без фреймворка (одна страница — фреймворк не нужен)
- **Тесты:** Vitest 5 (юнит, интеграция), fast-check (property-based),
  Playwright (E2E)
- **Линт:** ESLint 10
- **Демо:** статическая сборка `dist-demo`, публикация на GitHub Pages из CI
- **Android:** Capacitor 8 + Gradle, JDK 21, compileSdk 36, APK из CI
- **Windows:** Electron 45 + electron-builder (`win-unpacked`) + Inno Setup 6
  (`setup.exe`), сборка из CI на `windows-latest`
- **Данные:** `config/company.json` — единственный источник персонализации:
  из него берутся и `appId`, и имя, и версия для всех трёх сборок
- **Интеграции:** Telegram по deep link `t.me`/`tg://` — без токена бота в клиенте

## Ограничения

1. **Одна страница.** Один экран-сценарий, без роутера и многостраничности.
   Android и Windows показывают ту же страницу в обёртке.
2. **Предварительная цена — диапазоном** («от … до …»), без точного расчёта
   на клиенте и без обещаний фиксированной суммы.
3. **Бюджет — только на нейросеть.** Никаких платных хостингов, CMS, CRM,
   подписок и сертификатов подписи кода; статика, бесплатные тарифы,
   бесплатные минуты GitHub Actions.
4. **Все данные компании — в `config/company.json`**, не в коде, не в
   `android/` и не в `electron/` руками.
5. **Секреты — только в `.env` и secrets CI.** Токен Telegram-бота не попадает
   ни в APK, ни в установщик: из бинарника он извлекается тривиально.
6. **Каждая сборка — одной командой**, без ручных шагов в Android Studio
   и Inno Setup.
