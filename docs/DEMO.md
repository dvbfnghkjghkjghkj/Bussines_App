# DEMO.md — демо-версия для клиента

## Идея

Демо — это та же страница с данными клиента, но в режиме «только посмотреть»:
сверху висит плашка, кнопка отправки заявки отключена, ссылка на Telegram
скрыта. Клиент оценивает дизайн и сценарий, при этом заявки не улетают
в рабочий чат, а демо нельзя принять за готовую версию.

## Сборка

```bash
npm run build:demo     # → dist-demo/
```

Режим `demo` включает в Vite флаг `__DEMO__`, а страница по нему:

- добавляет плашку «Демо-версия: заявки не отправляются, кнопки записи отключены»;
- отключает кнопку «Отправить в Telegram»;
- скрывает кнопку «Написать в Telegram» в шапке;
- оставляет возможность скопировать текст заявки.

## Публикация

Демо живёт на GitHub Pages: `.github/workflows/pages-demo.yml`.

1. Запушьте репозиторий на GitHub.
2. **Settings → Pages → Source: GitHub Actions.**
3. Запустите workflow вручную или сделайте пуш в `main` — он сработает сам
   при изменениях в `src/`, `config/`, `index.html`, `public/`.
4. Адрес: `https://<аккаунт>.github.io/<репозиторий>/`.

Обновление — обычный пуш в `main`: workflow пересобирает `dist-demo` и
публикует заново. История деплоев видна в Actions.

### Если демо переедет на собственный хостинг

`dist-demo` — обычная статика с относительными путями. Достаточно выгрузить
содержимое папки в корень поддомена (`demo.example.ru`) по FTP/SFTP; правки
в коде не нужны.

## Ограничения

- Демо статическое: заявки не принимаются, статистики нет.
- Данные — те же, что в продакшене. Если в `config/company.json` появятся
  персональные телефоны менеджеров, лучше завести отдельный демо-конфиг и
  собирать демо с ним (пока не нужно).
- Индексация поисковиками: для приватного демо добавьте `Disallow` в
  `robots.txt` или включите защиту паролем на уровне хостинга.
- GitHub Pages отдаёт файлы публично — не кладите туда секреты.

## Проверка перед показом клиенту

- [ ] Плашка «Демо-версия» видна на первом экране.
- [ ] Кнопка отправки неактивна, подпись «Отправка в демо недоступна».
- [ ] Ссылки Telegram нигде не открывают рабочий чат.
- [ ] Страница открывается на телефоне и на ПК.
- [ ] В консоли браузера нет ошибок, картинки загружаются.
